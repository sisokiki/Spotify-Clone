# Spotify Clone 🎧

A responsive Spotify web application built with **React**, **Vite**, and **Tailwind CSS**. This project replicates the core features of the Spotify user interface, including album navigation, a functional music player, and responsive layout management.

## 🚀 Live Demo

Check out the live project here: [https://sisokiki.github.io/Spotify-Clone/](https://sisokiki.github.io/Spotify-Clone/)

## 🛠 Features

* **Music Player**: Play/pause control, track seeking, and automatic duration tracking.
* **Dynamic Routing**: Navigate between the home dashboard and individual album pages using `HashRouter`.
* **Responsive Design**: Mobile-friendly sidebar and responsive display grid powered by Tailwind CSS.
* **State Management**: Uses React Context API to manage global audio states and track information across components.

## 🏗 Built With

* [React](https://react.dev/) - Frontend library
* [Vite](https://vite.dev/) - Build tool and development environment
* [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
* [React Router](https://reactrouter.com/) - Client-side routing for seamless navigation

## ⚙️ How to Run Locally

1. **Clone the repository:**
```bash
git clone https://github.com/sisokiki/Spotify-Clone.git
cd Spotify-Clone

```


2. **Install dependencies:**
```bash
npm install

```


3. **Start the development server:**
```bash
npm run dev

```


Open your browser to the URL displayed in the terminal (usually `http://localhost:5173`).

## 📦 Deployment

This project is built for production and deployed using GitHub Pages. To redeploy after making changes, simply run:

```bash
npm run deploy

```
